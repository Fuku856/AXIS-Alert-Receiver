# AXIS Alert Receiver

AXIS Alert Receiver は、AXIS サーバーからの速報や通知を受信し、デスクトップ通知および独自のポップアップ画面でお知らせする常駐型アプリケーションです。

## 主な機能

- **リアルタイム通知**: AXIS API と連携し、新着メッセージを即座に受信・表示します。
- **デスクトップ通知**: OS ネイティブのトースト通知と、画像や詳細情報を表示可能なカスタムポップアップウィンドウに対応しています。
- **セキュアな認証情報管理**: Windows DPAPI (Data Protection API) を利用し、API トークンをローカル環境に安全に暗号化して保存します。
- **直感的な設定画面**: システムトレイ（タスクトレイ）アイコンから設定画面を開き、チャンネルごとの通知設定などを簡単に管理できます。

## インストールと使い方

1. 付属のインストーラー (`AXIS-Alert-Receiver_Setup_*.exe`) を実行し、画面の指示に従ってインストールしてください。
2. インストール完了後、アプリケーションを起動するとシステムトレイにアイコンが常駐します。
3. 初回起動時や未設定時は、システムトレイのアイコンを右クリックして「設定」を開き、有効な API トークンを入力して接続を確立してください。

## 動作環境

- Windows 10 / 11 (64-bit 推奨)
